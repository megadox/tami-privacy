타미 개인정보 처리방침

시행일: 2026년 10월 2일

타미 – 생활 주기 비서(이하 “앱”)는 사용자의 개인정보를 외부 서버로 수집하거나 전송하지 않습니다.

1. 저장하는 정보

앱은 사용자가 입력한 생활 관리 항목, 반복 주기, 완료 이력, 메모 및 앱 설정을 사용자의 기기 내부에 저장합니다. 이 정보는 개발자 또는 제3자에게 전송되지 않습니다.

2. 알림 권한

앱은 사용자가 등록한 예정일을 알려주기 위해 알림 권한을 요청할 수 있습니다. 사용자는 권한을 허용하지 않아도 알림 이외의 기능을 사용할 수 있으며, 기기 설정에서 언제든 권한을 변경할 수 있습니다.

3. 백업 파일

사용자가 내보내기를 실행하면 앱 데이터가 JSON 파일로 만들어져 사용자가 직접 선택한 위치에 저장됩니다. 백업 파일의 보관, 공유 및 삭제 책임은 사용자에게 있습니다. 앱은 백업 파일을 외부 서버로 전송하지 않습니다.

4. 제3자 제공 및 분석

앱은 개인정보를 제3자에게 제공하지 않습니다. 광고, 사용자 행동 분석 또는 외부 오류 수집 SDK를 사용하지 않습니다.

5. 데이터 보관 및 삭제

앱 데이터는 사용자의 기기에 보관됩니다. 개별 항목은 앱 안에서 삭제할 수 있으며, 앱을 삭제하면 기기 내부의 앱 데이터도 삭제됩니다. 사용자가 별도로 내보낸 백업 파일은 해당 파일을 저장한 위치에서 직접 삭제해야 합니다.

6. 아동의 개인정보

앱은 개인정보를 수집하지 않으며 아동을 대상으로 개인정보 입력을 요구하지 않습니다.

7. 처리방침 변경

앱의 데이터 처리 방식이 변경되는 경우 이 문서와 Google Play 데이터 보안 정보를 업데이트하고 시행일을 고지합니다.
